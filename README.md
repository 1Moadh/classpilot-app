# ClassPilot

ClassPilot is an offline gradebook and classroom app for teachers.

**Open the app:** https://1moadh.github.io/classpilot-app/

- Your class files stay on your computer (or in your own OneDrive folder). The app opens and saves them with your permission and sends nothing anywhere.
- Works in current Microsoft Edge, Google Chrome and Brave on Windows 10/11.
- To use it offline, save this page (`index.html`) to your computer and open it by double-clicking.

This repository contains only the published app. It is updated automatically from tested versions.
